# SP6 Final TFM

Proyecto independiente para construir desde cero un Trabajo Fin de Máster sobre coordinación distribuida de robots móviles autónomos.

## Título de trabajo

**Arquitectura escalonada para la coordinación distribuida de AMR cooperativos para cargas heterogéneas**

AMR significa *Autonomous Mobile Robot*. El proyecto no reutiliza capítulos, resultados, hipótesis, bibliografía ni decisiones científicas del manuscrito anterior.

## Estado

Fase 0: configuración académica pendiente de confirmación.

Hasta confirmar `PAPER_CONFIGURATION.md`, no se redactarán afirmaciones científicas, no se seleccionarán algoritmos y no se incorporarán citas.

## Estructura

- `manuscript/`: futura memoria y sus capítulos.
- `research/`: preguntas de búsqueda, corpus verificado y matriz de literatura.
- `experiments/`: protocolo, datos y análisis reproducibles.
- `figures/`: figuras derivadas de evidencia.
- `DECISIONS.md`: registro de decisiones y cambios de alcance.
