# Optional authentic Web of Science input

Drop untouched WoS exports in this directory when available.

Preferred export content: **Full Record and Cited References**.

Use multiple raw files if the interface imposes export-size limits. Do not merge or edit them manually.

Typical accepted extensions:
- `.txt` / tab-delimited `savedrecs.txt`
- `.csv`

Useful WoS fields include:
- `UT` accession ID
- `DI` DOI
- `TI` title
- `AU` authors
- `PY` year
- `SO` source/venue
- `AB` abstract
- `DE` author keywords
- `ID` Keywords Plus
- `TC` citation count
- `CR` cited references
- `DT` document type

Absence of WoS does not block Stage 1A open-source discovery, but final claims must state that WoS reconciliation is pending.
