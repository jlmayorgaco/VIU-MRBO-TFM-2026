# Fichas de lectura cercana V3

Esta carpeta contiene fichas de evidencia elaboradas a partir de texto completo
o de pasajes identificados con localizador. No son todavía prosa de la memoria
ni autorizan una afirmación fuera de su alcance.

## Regla de uso

Cada ficha debe separar con claridad: identidad bibliográfica, pasajes revisados,
alcance que la fuente sí respalda, limitaciones y afirmaciones que la fuente no
permite realizar. Una fuente solo puede utilizarse en la síntesis si conserva un
localizador verificable y su tipo de evidencia es coherente con la afirmación.

El estado `lectura_cercana_verificada` significa que se inspeccionaron los
pasajes indicados de la copia local. No equivale a que el resultado sea
generalizable, a una replicación, ni a una demostración formal de las
propiedades estudiadas.

La cola y la trazabilidad global se generan desde:
`academic-review/literature-review-v3/data/priority_reading_queue_v3.csv` y
`academic-review/literature-review-v3/data/review_cards_v3.jsonl`.
