# Procedencia de resultados

Las tablas, macros y gráficos de este subdocumento son una instantánea de las
campañas N1 v2, N2 v1, N3 v2, N4 v2, N4 v3 y N4 v4. Los manifiestos y métricas
clave preservados aquí permiten identificar la versión de cada campaña.

El contenido de `generated/` y `assets/figures/` es el que LaTeX utiliza para
la compilación. Esta carpeta no sustituye los datos crudos ni el entorno Python
del repositorio principal; evita que una revisión de redacción cambie los
resultados publicados de forma implícita.
