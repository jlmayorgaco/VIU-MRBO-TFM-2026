\begin{viuabstract}
El transporte cooperativo de cargas en almacenes automatizados requiere coordinar
flotas de AGV de modo que cada tarea cuente con el número mínimo de robots
exigido para su manipulación segura. En el corpus revisado, los enfoques
distribuidos más próximos no formulan simultáneamente esta restricción de
cardinalidad mínima y una ley de revisión continua, y los métodos evolutivos
suelen suponer grupos de tamaño fijo o estimaciones globales del payoff poco
compatibles con topologías de comunicación irregulares.

Este TFM caracteriza, mediante una escalera comparativa incremental de cinco
tratamientos, qué nivel de coordinación se requiere para resolver el problema de
forma distribuida: desde una heurística voraz local hasta una referencia
centralizada replanificada, pasando por la estimación por consenso, el replicador
distribuido y las dinámicas de Smith. El método propuesto (tratamiento~T4) combina
tres elementos cuya integración conjunta no se ha identificado en el corpus
bibliográfico revisado: (i)~las dinámicas de Smith como ley de asignación
distribuida, (ii)~un payoff multiplicativo con componente sigmoide monótonamente
decreciente en la ocupación estimada de cada tarea, que preserva, en el caso base
($\Psi \equiv 1$), la estructura de juego de congestión, y (iii)~una tasa de
revisión espacialmente modulada que
reduce reasignaciones innecesarias.

El método acopla tres dinámicas en un único bucle de control ($T_s = 0{,}1$\,s):
estimación de estado por consenso distribuido, dinámicas de Smith proyectadas
sobre el símplex, y campo de gradiente reactivo para navegación cooperativa con
evitación reactiva de obstáculos estáticos.
Para el caso base (factor espacial constante y comunicación global), el
Teorema~\ref{prop:convergencia} establece la estabilidad asintótica local del
equilibrio Nash objetivo dentro de un intervalo acotado de la pendiente del
payoff; el sistema implementado, con comunicación local, transición
reclutamiento--transporte y obstáculos, se trata como una versión perturbada del
juego base y se evalúa empíricamente.
Este trabajo aborda la capa de asignación y formación de coaliciones;
la coordinación de fuerzas de contacto para empujar o agarrar la carga
(capa de manipulación cooperativa) es una capa complementaria fuera del alcance.
La validación cuantitativa en Python contempla seis escenarios con cinco
tratamientos comparativos y al menos treinta repeticiones por combinación; la
validación cualitativa se realizará en CoppeliaSim con robots Pioneer~3-DX.
Se formula además una extensión a cargas de capacidad heterogénea, explorada a
nivel de formulación y en un escenario adicional.

\keywords{dinámicas de Smith, juegos de congestión, formación de coaliciones,
  transporte cooperativo multi-AGV, control distribuido.}

\vspace{0.4em}
\noindent{\bfseries\color{VIUOrange}Keywords:}\enspace Smith dynamics, congestion
games, coalition formation, multi-AGV cooperative transport, distributed control.\par
\end{viuabstract}
