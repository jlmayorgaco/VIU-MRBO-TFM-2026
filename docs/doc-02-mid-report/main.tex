%--- Resumen (pag 3)
\begin{viuabstract}
El transporte cooperativo de cargas heterogéneas en almacenes automatizados
requiere coordinar flotas de AGV capaces de asignarse a tareas que demandan
distintos números mínimos de robots. Este trabajo estudia si un esquema de
coordinación distribuida local, basado en consenso dinámico de media y dinámicas
poblacionales, permite integrar en un mismo bucle temporal la estimación de
ocupación, la asignación a cargas, la formación de coaliciones y la navegación
reactiva, sin coordinador central de asignación.

La metodología sigue una lógica comparativa e incremental. Se evalúan cinco
tratamientos: una heurística voraz local, un esquema con consenso dinámico y regla
voraz, un replicador distribuido, dinámicas de Smith con revisión modulada y una
referencia centralizada replanificada. El método propuesto combina las dinámicas de
Smith, un payoff sigmoide decreciente asociado a la cardinalidad mínima y una tasa
de revisión espacialmente modulada. En el caso base con $\Psi \equiv 1$, el payoff
induce una estructura de juego de congestión y se establece la estabilidad local del
equilibrio objetivo; con $\Psi(d)$ activo, el sistema se interpreta como una
perturbación espacial evaluada empíricamente.

La validación cuantitativa se realizará en Python mediante seis escenarios y al
menos treinta repeticiones por combinación; la validación cualitativa y cinemática,
en CoppeliaSim con robots Pioneer~3-DX. El trabajo se limita a la capa de asignación,
formación de coaliciones y navegación; la manipulación cooperativa por contacto queda
fuera del alcance.

\keywords{coordinación distribuida, formación de coaliciones, consenso dinámico,
  dinámicas poblacionales, transporte cooperativo multi-AGV.}

\vspace{0.4em}
\noindent{\bfseries\color{VIUOrange}Keywords:}\enspace distributed coordination,
coalition formation, dynamic average consensus, population dynamics, cooperative
multi-AGV transport.\par
\end{viuabstract}
