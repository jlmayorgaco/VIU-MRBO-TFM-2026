# Informe avanzado

Este directorio conserva la entrega `doc-04` como informe avanzado del TFM. Incluye fuente LaTeX, estilo VIU, secciones, figuras, imagenes institucionales, bibliografia y `main.pdf`.

Su rol es documentar el avance anterior a la memoria final. El material teorico extendido, la matriz de resultados pendientes y el anexo matematico se conservan para trazabilidad, pero la entrega canonica final esta en `docs/doc-05-final-report`.

Compilacion desde la raiz:

```powershell
make report-pdf REPORT_DIR=docs/doc-04-advanced-report
```
