\section{Hipotesis}

Las hipotesis se formulan como afirmaciones falsables. Cada una debe conectarse con una
metrica, un escenario y una salida reproducible del repositorio.

\begin{tabularx}{\textwidth}{@{}p{0.13\textwidth}X X@{}}

\midrule

Ademas de las hipotesis base, la memoria conserva gates teoricos extendidos
G3--G7. Estos no sustituyen la evidencia experimental: delimitan por que la cardinalidad
no implica capacidad wrench, como la geometria entra en el torque, y bajo que lectura
la congestion predictiva y la bateria se incorporan al payoff.
