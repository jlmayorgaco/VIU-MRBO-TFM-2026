\section{Objetivos}

\subsection{Objetivo general}

Disenar, implementar y evaluar una arquitectura distribuida para la coordinacion de
coaliciones multi-AMR en transporte de cargas heterogeneas, usando dinamicas de Smith,
capacidad efectiva y validacion reproducible por simulacion.

\subsection{Objetivos especificos}

\begin{enumerate}[label=O\arabic*.,leftmargin=2.2em]
  \item Formular el problema como un juego de congestion y capacidad donde cada robot
  decide localmente su participacion en una tarea.
  \item Ordenar la contribucion en una escalera modular M0--M5 que parta de metodos
  clasicos y avance hacia coaliciones, heterogeneidad, roles fisicos, campo unico y
  bateria.
  \item Implementar Smith-QR como extension de Smith con memoria, estimacion local,
  clearing entero y guardias de quorum.
  \item Extender el criterio de quorum desde cardinalidad hacia capacidad efectiva en
  espacio \emph{wrench}.
  \item Comparar Smith-QR frente a Smith, greedy, centralizado limitado, CBBA/proxies y
  baselines MARL congelados.
  \item Organizar el repositorio para reproducir simulaciones, validaciones y reporte
  desde una unica estructura fuente.
\end{enumerate}

\subsection{Alcance}

El alcance defendible es simulacion reproducible en Python y evidencia visual en
CoppeliaSim. No se declara validacion fisica en hardware, certificacion de seguridad,
percepcion real ni despliegue industrial. MARL se usa como baseline aprendido y no como
contribucion teorica principal. La memoria distingue tres estados de madurez: modulos
implementados y validados en campanas principales, modulos demostrados por gates
matematicos o sinteticos, y modulos conservados como extension futura. En particular, M3
se reporta como asignacion de roles derivada por formacion, no como optimizacion completa
$y_{ikh}$; M5 se reporta como bateria en payoff, no como sistema completo de estaciones
de carga.
