# Superseded integrated certificate

`PHYSICAL_COALITION_CERTIFICATE_v1` is no longer canonical evidence.

The original sealed adaptive campaign remains recoverable from Git history. The files
currently present in this directory were regenerated for diagnosis after correcting
the dropout-recovery implementation; that rerun reused the historical protocol ID and
therefore cannot be represented as the original frozen campaign.

Use `PHYSICAL_COALITION_CERTIFICATE_v1_1_FIXEDN` for every thesis claim. It uses fresh
seeds, a separate protocol ID, a frozen hypotheses contract, 100 paired worlds in each
of four families, and a closed 2,400-run manifest. Results from this directory must not
be pooled with or substituted for the fixed-n campaign.
