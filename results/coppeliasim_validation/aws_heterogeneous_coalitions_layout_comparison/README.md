# Comparación pareada de geometrías AWS

El efecto es `centro abierto − cuello` sobre las mismas ocho semillas. Un valor positivo de entregas favorece el centro abierto; un valor negativo de esperas de reserva también lo favorece.

| Política | Entregas cuello | Entregas abierto | Esperas cuello | Esperas abierto |
| --- | ---: | ---: | ---: | ---: |
| MILP-Q | 3.125 | 0.750 | 923.8 | 2332.4 |
| Greedy-Q | 3.250 | 1.250 | 873.9 | 1978.6 |
| Random-Q | 0.500 | 0.875 | 4002.6 | 3663.5 |
| Replicator-Q | 1.375 | 1.375 | 2950.2 | 3237.5 |

Ninguna diferencia se interpreta como causal o general sin revisar su IC pareado y `p_value_holm`.
