# Validación complementaria en simulador

Estas carpetas contienen manifiestos, resúmenes, contrastes pareados y figuras de las escenas industriales utilizadas como validación complementaria. La evidencia canónica y sus limitaciones se registran en `docs/04_CLAIMS_EVIDENCE.md`.

Los trazados de alta frecuencia de movimiento, robots y cargas se conservan fuera de Git por su volumen. El repositorio sí versiona las tablas agregadas necesarias para auditar las cifras de la memoria, los manifiestos de ejecución, las configuraciones derivadas y las imágenes representativas. Los trazados locales excluidos siguen la convención `*_motion_trace.csv`, `*_robot_trace.csv` y `*_load_trace.csv`.

Esta validación no convierte el simulador en evidencia física ni amplía por sí sola las garantías formales del modelo reducido.
